# Start here: sample pack for Claude for Business, MAICON 2026

Five scenarios, each with sample material and a prompt for every exercise, so you can run the whole
workshop without putting your own company's material in front of a room of strangers.

Northwind Supply doesn't exist. Its data, notes and transcript are invented. The Trust Insights
competitive numbers are real and published, which is why that scenario uses them.

## What's in here

- **Sample Data**: what you give Claude, organized by the exercise where you first need it
- **Example Outputs**: what Claude produced from it, organized by exercise, so you can check your work or carry on if yours didn't finish
- **00-All-30-Prompts.md**: every prompt in the workbook, for every exercise in every scenario. Change the parts in [brackets] and send

The number at the front of each file is its scenario. Pick one scenario and follow its number all the way through.

| | Scenario |
|---|---|
| 01 | Competitive analysis |
| 02 | Content and editorial |
| 03 | Reporting and performance |
| 04 | Process and documentation |
| 05 | Meetings to actions |

## Sample Data

**Exercise 1 - Research.** One file per scenario. Attach yours in Exercise 1, and add it to your Project in Exercise 2.

- `01-Competitive-Visibility-Data.csv`: sixteen visibility metrics for four organizations
- `02-Content-Brand-Voice-and-Posts.md`: a thin brand voice note and three published posts
- `03-Reporting-Channel-Performance-Data.csv`: five months of channel performance, thirty rows
- `04-Process-Onboarding-Notes.md`: messy onboarding notes with no owner
- `05-Meetings-Pipeline-Review-Transcript.md`: a twenty-minute pipeline review

**Exercise 6 - Scheduled Task.** Scenario 4 needs one more file here.

- `04-Process-Distributor-Accounts.csv`: twelve distributor accounts, for the scheduled check

Exercises 2 to 5 don't need new data. They build on your Exercise 1 file and what came back from it.

Read it the way you'd read your own, and check it against the sample data.

- `05-Meetings-Synthetic-Commitments-Table.md`

**Exercises 3 to 5.** The finished worked example for scenario 1, competitive analysis.

- Exercise 3 - Artifact: `01-Competitive-Worked-Example-Scorecard.csv` (the finished scores, grades and ranks) and the same scorecard as a bar chart and a radar chart

## Using your own material instead

Every exercise works the same way on your own material. The sample files exist so that nobody is
stuck, and so that anyone whose data is sensitive can still take part fully. Using the samples isn't
the beginner path. It's the sensible path on conference wifi.
